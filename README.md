# swc-group38

> Group assignment submissions from the Software Construction course at the University of Zurich — 6 assignments covering software engineering principles, design patterns, and testing.

## ✨ TL;DR
```bash
npm install && npm start
```

## 🚀 Features
- **6 assignments:** Practical tasks on software engineering principles, from OOP to testing.
- **JavaScript/Node.js:** Web application with frontend (React) and backend.
- **Group project:** Collaboratively developed as part of the Software Construction course.

## 🎓 Academic Context
This project was created as part of a university course.
- **Course:** Software Construction (L+E)
- **Institution:** University of Zurich (UZH)
- **Semester:** Fall Semester 2020

---

## 🛠️ Installation

### Prerequisites
- Node.js 12+
- npm

### Steps
1. Clone the repository:
```bash
git clone https://github.com/HuberNicolas/swc-group38
cd swc-group38/SoftCon2020_Assignment_1
```
2. Install dependencies:
```bash
npm install
```

---

## 💻 Usage

```bash
npm start
```

Navigate to the relevant assignment directory (`SoftCon2020_Assignment_1` through `_6`).
